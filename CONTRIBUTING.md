# Contributing to ConfigCraft

Thank you for helping. Discuss large changes in an issue first. Keep generators pure, deterministic, typed, and independent from React; add tests for conditions and security boundaries. Never add credentials or telemetry.

Before a pull request, run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`. Explain user-visible behavior and security considerations. Contributions are licensed under Apache-2.0 and must follow the Code of Conduct.
